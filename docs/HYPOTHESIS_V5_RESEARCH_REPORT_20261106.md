# H01/H05 研究报告与交付状态

日期：2026-11-06。**策略后端已实现；统计优势没有得到验证；仍禁止真实交易。**

## 五格假设与预登记

H01：观察部分行情存在延续；假设收盘突破在大周期趋势和量能支持下可能有扣费后正期望；机制可能为分阶段调仓与跟随交易；验证采用原生永续时间切分、对照、消融和压力；否证条件包含样本外期望非正、置信不足、收益集中、成本压力不通过。

H05：观察 UTC 周末参与度可能变化；假设条件过滤可能改善执行；机制为深度/活跃度变化；同数据比较 A全天候、B周末不新增、C质量条件通过才新增；不优于 A 或证据不足均不支持优势。H02 假突破、H03 清算冲击、H04 资金费拥挤仅登记，无订单生成能力。

原始候选参数：EMA50/200、五根区间EMA50斜率、ADX14≥22；1H收盘突破此前20根高/低，量≥此前20根中位数1.2倍；止损2ATR、1.5R后跟踪3ATR，风险0.3%、日损2%、组合1.5%、最多两仓、止损后冷却8小时。没有因为结果不佳放宽默认阈值。

预登记门槛：单资产样本外至少30笔、净期望R>0、95%近似区间下界>0、最大盈利单占总盈利≤50%、成本压力期望>0。通过也仅为研究门槛，禁止自动晋级 Live。
