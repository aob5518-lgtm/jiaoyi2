# 生产兼容发布

生产现有后端版本标识为 `9b327da3627ad1a20cd03a61a770f5aa204b1a8b`，经典界面版本为 `eb840d7ad63905e7c4650f4b65bfe37a25317986`。它使用 `/api/v4/desk` 和账户连接接口，与H06研究分支的API不同。

本次采用前端兼容发布：`public/terminal/classic/` 保留生产控制器、表单和连接组件的原始逻辑，以新布局和样式组织这些数据。`BASE.json` 固定原生产资产哈希；不把H06参数或触发条件套用于经典账户，不更改交易引擎、Live权限、风险锁、迁移政策或账户数据。

- 单账户驾驶舱：资金摘要、当前报价、首仓/下次补仓/止盈价格、实际成交和历史记录。
- 右侧监控操作与参数摘要；侧边参数抽屉移动原有表单，保留原校验、持仓/运行中的禁用规则和保存接口。
- 原有账户新增、切换、Hyperliquid/Binance/Extended连接配置入口继续可用，密钥仍只显示配置状态。
- Live及归档账户保持原只读/受限状态，不能在新界面绕过服务器限制。

`scripts/deploy_workbench_ui.py` 校验原资产基线，建立带校验的完整应用备份（含依赖、配置、认证和全部账本），先发布以commit命名的不可变静态资产，再原子更新首页。没有后台重启，没有覆盖生产JSON。健康检查失败或发布异常只恢复界面，清理新静态文件，不回退新产生的财务状态。

本地已有437项全量自动测试通过，生产经典前端66个浏览器场景通过。发布工具的5个隔离故障/回滚场景分别覆盖正常发布、部分资产中断、首页更新后中断、基线不匹配、健康检查失败；其中确认回滚保留故障期间新增的历史记录。

生产实际UI commit、备份路径、校验值及不变性结果记录于服务器备份目录的 `deployment.json`。后端版本与UI版本分开记录，不能将前端热更新称作完整H06引擎部署。
