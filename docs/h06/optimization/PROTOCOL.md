# H06 第2轮优化：预先冻结的验证方案

基线：`3654944cfc26616b035b7ad2d59ddcf162a1b596`，PR #1。2024—2025的结果已被观察，因此本轮明确将其视为开发对照，不再次冒称独立样本外。

先修复工程诊断和验证缺口，再研究两个固定候选，不进行参数搜索：

- D 对照：原始交叉+最多3次补仓，默认1%/1%/2%/2%。
- I 实验：与D相同，但启用已有4H EMA20/50同向过滤（只有已收盘4H数据）。
- J 实验：I的过滤，最多1次等额补仓（原有B结构），控制后段加仓尾部风险。

不改变默认参数、不增加杠杆、不取消止损。所有方案固定BOTH、1x、初始权益10,000USDT和相同成本。

开发对照：2024—2025。新增未查看的时间区间：2026-01-01至2026-11-01（若官方月度档案可用）。在看到新期间结果前固定以上候选和费用假设。若数据不可用或缺证，明确记录阻断，不用已看过的时期替代独立验证。

验收指标：净收益、Profit Factor、最大回撤、最差单轮、95%尾部平均损失、按补仓次数/退出原因的收益归因、费用占比、交易数和覆盖范围。胜率只作描述，不作为提升默认的依据。

工程修复范围：

1. 报价失效时，当前权益/浮盈不得继续显示陈旧数字；保留带时间的最近有效快照。
2. 同一报价证据不能多次用于部分成交；重启后同样去重。
3. signalJournal应保留真正的提交/成交结果，不被后续等待状态抹掉。
4. 历史回放真正实现已有4H过滤开关，不能把未输入higherDirection的全阻断误当成策略结论。
5. 保留当前全部旧账户、旧策略参数和账本；不部署生产，不启用Live，不自动替换Shadow参数。

原始研究报告与源码指纹作为3654944历史基线保留，新结果单独存放，不改写成同一个实验。
