# H06 开发与安全审查记录

开发基线：GitHub main `0681f2b78cffd9fbaee316b5c10426c97df99fb1`。
开发分支：`codex/h06-macd-scale-in-v1`。

远端 main 与当前已部署的经典管理界面并非同一个版本。本分支从远端 main 独立开发，未覆盖生产目录，也没有把本地未合并的其他研究引擎混入 H06。正式合并与部署前需要再次检查主分支和生产代码差异。

## 结构与权限

- `strategy/macd_scale_in/config.js`：配置范围、固定安全边界、实验范围与配置哈希。
- `signal.js`：已收盘 1H EMA/MACD；默认 CROSS，MOMENTUM 与 COMBINED 独立实验。
- `book.js`：独立轮次状态机、风险检查、模拟订单、成交、费用、资金费、分批及完整结算。
- `provider.js`：仅 Binance USD-M 原生公开 REST 数据；不借用现货、其他交易所或旧账户缓存。
- `runtime.js`：先落盘订单，再处理模拟成交；账户与账本身份绑定、重启恢复和损坏保护。
- `terminal/h06-api.js`：H06 专属创建、配置、运行控制；统一终端读接口仍可查看。
- `public/terminal/h06.js`：沿用账户栏、导航、历史复盘和配置组件，不建立第二个网站。
- `scripts/h06_forward.js`：独立、本机绑定、需认证的只读 Shadow/Paper 研究主机。

`terminal/policy.js` 已注册 H06，但所有通用交易所下单入口对 H06 明确抛出 `H06_NO_REAL_ORDER`，包括 reduce-only。H06 的订单只能进入自己的模拟执行器。兼容配置入口不能变更 H06 的模式、身份、权益或策略；批量启动跳过 H06。旧策略迁移审计和旧 Live 退出路径保留。

## 冻结的交易语义

1. 默认 A：上一根 DIF≤DEA、当前 DIF>DEA 做多；做空对称。交叉多根确认时仅在最后一根确认完成后产生一次信号。
2. B：过去已知柱体形成转折后，连续 `momentumConfirmBars` 根向相同方向变化；不引用未来柱。
3. C：已确认交叉，且最近 `momentumConfirmBars` 个柱体变化均与交叉方向一致；不把一根交叉自动视为组合确认。
4. 首仓和补仓消费不同的已收盘信号 ID。暂停不撤除止损保护，不代表已经退出。
5. 各层预算锁定轮初已结算权益：1%、1%、2%、2%；最多三次补仓，后端限制保证金总额不超过6%。杠杆默认1x、研究硬上限5x。
6. 同向补仓必须按完整预计退出成本计算仍亏损。反向亏损信号在仍有层级时记录并等待，不能直接破坏补仓机制。
7. 本轮净ROI达到100%后，按数量精度平50%，仅一次，随后禁止补仓；剩余仓位等新反向信号退出。
8. 未达到ROI目标但已盈利时，默认遇反向信号全平。层级耗尽后仍亏损，遇反向信号全平。
9. 强制止损、日亏损与未知订单优先于新增仓位。单轮净亏损预算最多1%、日亏损最多2%。止损价格按压力退出滑点计算，只允许收紧，不能放宽以容纳补仓。
10. 每次补仓检查合并仓位的保守退出风险。允许拒绝，绝不保证三层都能成交。
11. 低杠杆首仓名义金额可能小于风险预算；止损价仍保持正数并按价格步长向安全侧取整。预算不等于一定亏掉的金额。
12. 日亏损以UTC日初净权益为基准，跨日仓位只统计当天权益变动，不重复计入昨夜浮亏。
13. 跳空、断网及极端滑点下，实际亏损可能超过预算。代码如实记录，不将风险限额表述为成交保证。

## 核算

- `netPnl = realizedGross + remainingGross - entryFees - exitFees - estimatedRemainingExitFee + fundingPnl`；预计剩余退出价包含滑点。
- ROI分母为本轮累计实际成交保证金；部分退出后不缩小分母制造虚高ROI。
- 权益只在完整轮次结算后更新；部分退出及资金费保留在当前轮次。
- 实时资金费使用 Binance 返回的实际历史费率、结算标记价和本账户当时数量。按资金费事件时间去重，并先于该时刻的分批成交结算。
- 如果资金费证据不完整：冻结新增风险，保留风险锁并允许有效报价下保护退出；仓位即使已退出，仍保持 `RECONCILING` 和风险锁，不生成已核对的财务结算；成本补齐后方可结算，风险锁不会自动解除。
- 分层入场只做一次有界模拟成交，剩余量取消；不能靠轮询不断把同一个盘口重复计算为新成交证据。
- Paper/Shadow模拟数量由真实公开买卖报价、显示数量、配置参与比例和合约规格限制。仍然是模拟撮合，不声称等同交易所实际成交。
- 活动轮次持有完整配置快照，新配置只作用于下一轮；参数变化不会重新标记旧历史。

## 未开放的能力

Live、交易所真实下单、真实撤单、杠杆调整及转账均未接入 H06。未提供强制解锁、清空旧历史或旧账户自动迁移。

没有历史逐笔订单簿时，OHLC回放无法证明真实的限价/市价成交；精确资金费结算标记价缺失时，也不能伪造。本轮研究报告列出其代理假设与缺口。收益尚未验证，不能据此开放实盘。

ATR结构实验使用入场前已收盘窗口的结构高/低点及ATR缓冲，并与固定净亏损保护取更安全的一侧，后续仅收紧。不是根据未来结构移动止损。
