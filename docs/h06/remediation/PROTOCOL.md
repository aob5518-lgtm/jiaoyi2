# H06 专项整改研究方案

固定基线：9c6d356a59fe61e6e76f06de491ca5b2a740ec14，草稿 PR #1。本轮不合并main、不部署、不接触生产账户或真实交易权限。

所有2024—2025及2026-01-01至2026-06-29（右端不含）数据均已被查看。本轮全部标为已使用历史数据的研究，不重新声称独立样本外。维持相同两币种、两时期、10,000USDT、BOTH研究方向、费用/资金费/保守OHLC撮合；正式默认LONG_ONLY及其余参数不变。

预先固定研究矩阵，不按收益追加搜索：

- 原12组D/I/J重放，逐组核验最高观测净ROI、达到目标80%的轮次数、目标触发/提交/部分成交/完成事件、反向提前退出与硬止损原因。最高ROI为真实管理时点的路径观测，不用最终MFE除最终保证金倒算。
- 杠杆/目标：1x、3x、5x × 20%、100%净保证金ROI，共6种。每组独立权益、订单和实验ID，不累加不同实验收益。
- 尾部：D三次补仓、不补仓N0、仅一次N1、当前净亏损达到冻结轮次风险预算50%后阻止新增补仓G50、保留全部硬止损但关闭反向信号软退出HARD_ONLY。G50及HARD_ONLY仅在离线回放事件适配层实现，不能写入正式配置。
- 指标：净期望、Profit Factor、标记最大回撤、最差轮次、亏损轮次尾部5%均值、费用、持仓阶段成本/最大浮亏/风险贡献及最终分层收益。

接近目标统一定义为最高观测ROI达到目标80%；反向提前退出定义为反向原因退出且此前未达到目标。未平仓另列，不伪造期末成交。阶段风险为当时全部已成交仓位在当前止损及压力滑点下的净风险；最终按各层真实数量、退出和资金费分摊，非因果效应。

工程变更只修配置快照、订单事实、展示和观测；D/I/J旧结果先数值复核。Binance原生公共接口在独立本机目录验收；不可达则明确阻断。合成恢复/生命周期测试与真实前向验收严格分开。
