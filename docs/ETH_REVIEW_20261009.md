## 本轮修复

1. 16 根微窗口不足以可靠识别三次确认 swing，V3 结构与前方结构搜索改为独立 48 根；左右各 2 根确认不变，不读未来数据。
2. 延续压缩—释放分阶段识别：已确认压缩最多有效 3 根；结构、压缩、释放仍须同时有效。延续候选从 0 增为 3 根，其中一根评分不足、两根结构止损过远，仍不下单。
3. 候选按质量选择；无效止损的高分突破不能压掉有效回踩。偏震荡区仍只允许高质量回踩。禁止追单的突破不再否决独立有效回踩。
4. 突破止损使用最新已确认 setup pivot，避免机械使用整个区间另一端；远 pivot 仍拒绝，不截短止损掩盖风险。信号阶段即明确标识无效止损。
5. 同方向持续几天不再被当成一个永不恢复的波段：完全冷却后，必须 high/low 两个结构都沿交易方向更新，才开启新 wave。每 wave 仍最多 2 次、单仓与所有风险门槛保留；只有真实成交才提交 wave 状态。
6. V3 诊断保留 14 天，每次 status 仍最近 50 条。记录候选因素、止损拒绝原因、版本修订与真实覆盖范围。事后趋势比例只使用成熟 32 根样本，不混用不同 horizon，不把重叠 K 线当成独立交易。
