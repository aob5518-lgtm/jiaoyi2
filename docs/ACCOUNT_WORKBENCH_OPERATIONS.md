# 账户管理与当前持仓显示整改

本轮只调整账户操作权限、只读展示及前端流程。没有修改任何策略的指标、风险比例、入场、退出、杠杆参数或账本收益计算。所有现有研究策略继续 Paper-only，新增真实账户连接不授予这些策略的 Live 执行能力。

## 使用

- 管理账户 → 新增账户 → 选择“模拟账户”或“真实账户连接”。真实连接明确确认后创建为 connection_only、Live、停止状态，不自动调用下单、撤单、杠杆或转账接口。真实账户不接受手工填写模拟权益，交易所 API 配置直接展开。
- 在管理账户中搜索、切换并编辑账户。已有账户的交易类型、交易所、币种不允许通过连接编辑静默改变。空密钥不覆盖旧值。
- “删除账户”是可恢复的移出日常列表。配置、凭据、原账户 ID、全部历史和账本仍在原处。管理账户可找到“已删除”记录并恢复显示，不自动启动策略。
- 删除前后均核对状态。运行中、持仓、待确认委托、退出流程、损坏账本、身份不符和风险锁都会阻断；旧 Live 必须实时核验所有原生市场的持仓和挂单，不能仅依赖本地缓存。没有强制删除或清空账本接口。旧 /api/account/delete 继续拒绝危险删除。
- 当前交易区显示“当前持仓均价 / 本轮开仓杠杆 / 数量”。Paper 使用当前仓位锁定配置，与右侧下一轮参数分开。经典补仓均价为实际成交后的加权均价，不以计划首仓价替代。
- 真实账户只从交易所读取持仓数量、均价和杠杆，缺失值标为待核验。支持展示双向及其他合约持仓，保留完整合约与计价币种；原生未实现盈亏明确注明未扣预计退出成本，不冒充净收益。

## 额外修复

- 修复连接更新与删除预览在未取得锁时误清除其他请求 terminalMutating 的问题。
- 原生账户查询共享在途请求，设 12 秒等待上限，正常缓存最多 10 秒。更新凭据后立即使旧缓存失效，旧请求的迟到结果不能覆盖新连接。
- 断流后不沿用陈旧持仓或将未知数据显示成空仓、零均价、零杠杆。
- 切换账户清除旧筛选，避免已切换账户被搜索框隐藏。
- 操作结果同时显示在表单按钮旁；手机长表单的保存、切换和删除按钮保留可见区域。
- 资金费率对冲单独标注永续腿均价和杠杆，未成交的永续腿不显示为已开仓。

浏览器 **94 场景通过**，视口为 1920×1080、1600×900、1440×900、1366×768、390×844、375×812。包含 64/100/150 账户、当前持仓数据、下一轮配置与本轮杠杆差异、真实连接新增、运行中删除阻断、空仓删除及恢复。账户卡最小高度 90px，无文字重叠或横向溢出。真实连接场景使用虚构账户，未访问生产私钥或提交真实订单。

本轮不自动创建、删除或恢复任何生产账户。部署保留全部配置、认证、历史和运行时，通过代码备份及状态校验后再重启。
