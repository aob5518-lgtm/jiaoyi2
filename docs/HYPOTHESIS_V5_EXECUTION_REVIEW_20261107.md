# H01 执行一致性复核（2026-11-07）

本次只修复隔离研究引擎的执行一致性，不部署生产，不启用 Live，不发送真实订单。V3、Short-Term、4H 的代码及参数保持不变。

## 已复现及修复

1. 待成交订单重新报价后重新反推数量，可能把已提交的 6.467 ETH 成交成 6.472 ETH。成交量现在同时受原提交数量、原风险预留及最新允许数量约束；部分成交后取消余量，记录原订单剩余数量。
2. 初始止损未按 priceTick 对齐。现在多头向下、空头向上对齐，再以实际距离反推数量，避免扩大账户风险。
3. 风险预留或计划数量缺失时不得产生 NaN 仓位，保留 UNKNOWN 并锁定研究账本。
4. 旧研究版本关闭仓位、读取接口时不能被重新标注为新版本。保留原 revision/configHash，旧版本禁止新增风险，未知订单继续保护，已有仓位仍保留保护与审查。前端禁用旧实验启动，并明确要求建立独立新实验。
5. 订单过期、取消、重报价拒绝分别显示最终执行状态，不能误显示为无策略信号。

修复后的 revision 为 H01_20261107_RESEARCH_V2，configHash 纳入 revision。所有 H01 数值默认参数与前一版本逐项一致。新旧实验不得合并收益。
